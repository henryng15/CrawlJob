# 7.9 Review queue

> Part of **7. Functional Requirements**

Each card must show:

- company;
- role;
- location;
- source;
- fit score;
- sponsorship classification;
- sponsorship evidence;
- resume version;
- completed field count;
- manual field count;
- session state;
- session expiration;
- application age;
- actions.

Actions:

```text
Open Filled Application
Prepare Replay Now
View All Answers
View Tailored Resume
Compare Resume
Mark Submitted
Skip
Discard
Report Incorrect Field
```
