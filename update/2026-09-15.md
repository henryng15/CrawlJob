## Direct Target versus Automatic runbook

- Added [direct-target-campaigns.md](../docs/direct-target-campaigns.md): a standalone operating guide for scheduling a scoped direct Target recruiter/referral campaign while `outreach`, `referral`, and `followUp` remain `Pause`. It records the independent Script Property → Target mirror → Target-only tick path, the actions that must never activate Automatic, and the required preflight, accounting, cancellation, and deployment-verification guards.
- Clarified deferred delivery authority: an explicit request to “send <scope> on <date/time>” authorizes a bounded direct Target campaign and its later Target-only tick; a request to prepare, draft, queue, or schedule only does not. This prevents a false requirement for a second chat command at the scheduled minute while retaining the no-send rule for plan-only work.
